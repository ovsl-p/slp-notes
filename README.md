# slp-notes

Oversleep の学習メモ（Obsidian vault）。Rust / web / 数学 / サウンドデザイン。

- `_index.md` — 目次（MOC）。新しいノートを足したらここにも追記する
- `_templates/study-note.md` — ノートの雛形
- `AGENTS.md` — 書くとき・直すときのチェックリスト（コミット前に確認）。`CLAUDE.md` はこれを読み込むだけ
- `programming/` `web/` `math/` `sound-design/` — ドメイン別
- `assets/<domain>/` — 画像・音源などの添付（ノート本文とは分ける）

Obsidian でこのリポジトリのルートをそのまま vault として開く。
