# フィルタはなぜフィルタになるのか

## ひとことで

遅らせた音を足すか引くかで、通る周波数と消える周波数が決まる。フィルタの正体はこの干渉。

## なぜ効くか / どこで使うか

LPF・HPF・コム・EQ・フランジャーは、どれも遅らせて足すか引くかの仲間に入る。ここが分かると、フィルタのつまみが何をしているのか読めるようになる。

カットオフはどの周波数から干渉させるかを動かし、Q は干渉の強さを動かす。遅延を長くするとコム（ノッチが等間隔に並ぶフィルタ）になり、ノッチの間隔が聴こえる領域に入るとフランジャーとして聞こえる。

音を削る箱としてではなく、**時間をずらしたコピーとの干渉**として見ると、この先の話が全部つながる。

## 前提となる知識

| 知っておくこと | なぜ必要か |
| --- | --- |
| 正弦波と位相 | 干渉は同じ周波数の波が同相か逆相かで決まる。位相が読めないと何も見えない |
| サンプリングとサンプルレート | 1サンプルの遅れが何 Hz の位相ズレになるかは SR で決まる |
| dB の読み方 | -6dB が半分、-20dB が 1/10。数字で挙動を追えるように |
| 足し算と引き算 | LPF は足し算、HPF は引き算。それだけで低域が残るか消えるかが決まる |
| 群遅延の基礎 | 遅れが周波数によって違うという感覚（詳細は [[FIR と IIR の違い]]） |

## 本体の解説

### なぜ「足し算」でフィルタになるのか

入力を足すだけなら元の音が大きくなるだけでは、という疑問はもっともで、答えは足す前に遅らせていることにある。

`y[n] = b0·x[n] + b1·x[n-1]` は、今の音と1サンプル前の音を足している。この2つは同じ波形ではない。遅れ k サンプルは、周波数 f に対して `2πfk/fs` の位相ズレになる。

低い周波数では1サンプルの遅れが小さな位相ズレにとどまり、2つの波がほぼ同相になって強め合う。高い周波数では位相ズレが180°に近づき、逆相になって打ち消し合う。ローパスが低域を通すのはこのためで、音量が一様に上がるのは 0Hz（DC）だけになる。

実測（48kHz、係数和が1になるよう正規化したフィルタに正弦波を通し、出力と入力の振幅比を測ったもの）:

4タップ箱型（`0.25, 0.25, 0.25, 0.25`）

| 周波数 | 出力/入力 |
| --- | --- |
| 0 Hz | 0.00 dB |
| 100 Hz | -0.00 dB |
| 1 kHz | -0.09 dB |
| 4 kHz | -1.55 dB |
| 8 kHz | -7.27 dB |
| 10 kHz | -13.75 dB |
| 12 kHz | -229 dB（完全に消える） |

2タップくし型（1ms、48サンプル遅らせて足す）

| 周波数 | 出力/入力 |
| --- | --- |
| 0 Hz | 0.00 dB |
| 250 Hz | -3.01 dB |
| 500 Hz | -254 dB（消える） |
| 1 kHz | 0.00 dB |
| 1.5 kHz | -244 dB（消える） |
| 2 kHz | 0.00 dB |

同じ足し算でも、500Hz は消えて 1kHz はそのまま通る。1ms 遅らせて足すだけで作れるこのくし型が、フランジャーの原理になる。

### すべての FIR は「コムの重ね合わせ」

FIR は遅延長の違うコムを足し合わせたものになる。各タップが k サンプル遅らせたコピーにあたるので、原理はどれも同じになる。

違うのはノッチの間隔と深さで、間隔はサンプルレートを遅延サンプル数で割った値になる。

| フィルタ | ノッチの間隔 | 耳での聞こえ方 |
| --- | --- | --- |
| 1サンプル遅延（20.8µs） | ノッチは 24kHz 付近 | 聴こえない（可聴域の外） |
| 1ms 遅延（48サンプル） | 1kHz ごと（実測: 500 / 1500 / 2500Hz が消える） | はっきりコム。フランジャーそのもの |
| 4タップ箱型 | 12kHz に1つだけ | ほぼ気づかない |
| 257タップ LP | 阻止域に 187Hz 間隔（実測 -75〜-86dB） | 通過域が平坦なのでコムに聞こえない |

257タップの通過域 20〜600Hz の偏差は 0.056dB で、ほぼ平らになる。多数のコムが干渉し合った結果、通過域では打ち消し合って平坦になる。

コムが欲しいときは遅延を1ms以上に伸ばす。IIR のコムはフィードバックでピークが鋭くなる。ノッチが完全に0まで落ちるのは、足すだけのコムのほうになる。

### 「坂」と「コム」は同じものの2つの見え方

LPF が坂に見えるのは、歯（ノッチ）の間隔が細かすぎて平均化されるためになる。

2タップ（原音 + D サンプル遅らせたコピー）の応答は `|cos(πfD/fs)|` で、山谷の数は遅延が位相を何回転させるかで決まる。

| D（サンプル） | 遅延 | 0〜20kHz の位相回転 | ノッチの本数 | 見え方 |
| --- | --- | --- | --- | --- |
| 1 | 0.02ms | 0.4 回転 | 0本 | なだらかな坂（ノッチは24kHzに1個だけ） |
| 4 | 0.08ms | 1.7 回転 | 2本 | まだ坂 |
| 16 | 0.33ms | 6.7 回転 | 7本 | うねりが見え始める |
| 48 | 1.0ms | 20 回転 | 20本 | はっきりコム |
| 257 | 5.4ms | 107 回転 | 107本 | 歯が細かすぎて坂に見える |

D が1サンプルなら、0〜20kHz で位相はまだ半回転もしていない。だから山谷が1つも入らず、ただのなだらかな坂になる。これが1サンプル遅らせて足すフィルタの正体で、コムにはならない。

遅延を長くすると位相が何度も回り、強め合う点と打ち消す点が交互に現れる。20kHz までに入る歯の本数は、遅延サンプル数のおよそ0.42倍になる（48サンプルなら20本）。

多タップの FIR は D の違うコムを足し合わせたもので、足すと山谷が平均化されて滑らかな坂になり、細かいリップルだけが残る。N=257 ではそのリップルが 187Hz 間隔で -75〜-86dB になり、間隔が細かく深さも浅いので坂に見える。

**歯の間隔が広ければコム、細かすぎれば坂。同じ干渉を粗さの違うスケールで見ている。**

### なぜハイパスは低域が消えるのか

ローパスが足し算なら、ハイパスは引き算になる。

```
ローパス:  y[n] = 0.5·x[n] + 0.5·x[n-1]    ← 足す
ハイパス:  y[n] = 0.5·x[n] − 0.5·x[n-1]    ← 引く
```

低い音は1サンプルの間で値がほとんど変わらないので、差を取るとほぼ0になる。0Hz では完全に0になる。

引き算はコピーの位相を180°反転して足すことにあたる。DC はコピー間に位相差がないので、反転すると完全な逆相になって必ず消える。ナイキスト（サンプルレートの半分の周波数）はコピー同士が180°ズレているため、反転すると同相になって通る。

実測（48kHz、`0.5, -0.5` の2タップ）:

| 周波数 | ゲイン |
| --- | --- |
| 0 Hz | -240 dB（完全に0） |
| 20 Hz | -57.7 dB |
| 100 Hz | -43.7 dB |
| 1 kHz | -23.7 dB |
| 5 kHz | -9.9 dB |
| 20 kHz | -0.3 dB |

一定値（DC）を入力して出力の最大値を測ると 0.0 になる。

多タップでも同じで、ハイパスはデルタからローパスを引く形（スペクトル反転）で作れる。実測（N=257、fc=1kHz）では 0Hz が -240dB、100Hz が -80.4dB、500Hz が -74.2dB、1kHz が -6.0dB、5kHz が 0.0dB になる。

LPF と HPF の応答を足すと全周波数で 1.0 になる（実測の誤差は 1e-15 のオーダー）。ハイパスがローパスで通した分を元の音から差し引いた残りになっていることが、この数字に出る。

実務での注意:

- ハイパスは位相が反転するので、ローパスと並列に混ぜると打ち消し合って音が消えることがある
- 消えるのは DC だけで、実際は坂になっている。20Hz 以下を落としたいなら次数を上げる必要があり、そのぶん遅延が増える
- 2タップのハイパスは1次フィルタなので、傾きは 6dB/oct になる。実測でも 100Hz の -43.7dB から 1kHz の -23.7dB まで約 20dB/decade で落ちる

#### 注意: 「引き算」がそのまま当てはまる範囲

デルタからローパスを引く形でハイパスを作ると、ローパスのレゾナンスはそのまま引かれて同じ場所に谷ができる。実際、FIR でデルタから LPF を引くと、応答の和は全帯域で 1.0000 になり、カットオフでは両方が -6.0dB になる。

普通の IIR ハイパスは引き算で作っていない。バタワース系では零点の位置が違い（LP はナイキスト、HP は DC）、単純な引き算の関係にならない。実測（RBJ、fc=1kHz、Q=5）では、カットオフ付近が LP +14.0dB、HP +13.9dB、1.5kHz が LP -2.2dB、HP +4.8dB になる。

IIR のハイパスは自分でレゾナンスを持ち、Q を上げればカットオフ付近に山が出る。引き算によってレゾナンスが消えるのは、デルタから引く形で作った場合に限られる。

### タップ数と次数

次数とタップ数は別物になる。FIR では次数がタップ数から1を引いた値で、257タップなら256次にあたる。IIR では次数が極の数になり、2次はバイクアッド（2次のIIRフィルタを1ブロックにまとめた形）1個、4次はその2個の縦続を指す。

次数がそのまま急峻さになる（実測、LPF fc=500Hz）:

| 次数 | オクターブあたりの減衰 | カットオフでの減衰 |
| --- | --- | --- |
| 2次 | 12 dB/oct | -3.0 dB |
| 2次の縦続2段（4次相当） | 24 dB/oct | -6.0 dB |
| 2次の縦続4段（8次相当） | 48 dB/oct | -12.0 dB |

カットオフの値が -3dB でなく -6dB、-12dB になっているのは、同じ2次フィルタを重ねた測定だからになる。4次や8次のバタワースとして設計すれば、カットオフは -3dB になる。

FIR で同じ急峻さを出すには数百タップが要り、次数もその数になる。

## 具体例・コード

2タップのフィルタを素直に書くと、干渉の正体がそのまま見える。

```python
# ローパス: 足し算
y[n] = 0.5 * x[n] + 0.5 * x[n-1]

# ハイパス: 引き算
y[n] = 0.5 * x[n] - 0.5 * x[n-1]

# コム（1ms = 48サンプル遅らせて足す）
y[n] = 0.5 * x[n] + 0.5 * x[n-48]
```

3つとも、今の音と少し前の音を混ぜている。混ぜ方（足す、引く、遅延量）が違うだけで、LPF・HPF・コムになる。

## つまずきポイント

- 足すと音量が上がると思う。係数の和が1なら音量は変わらず、上がるのは DC だけになる。
- 全部コムではと思う。遅延が短いとノッチの間隔が広すぎて可聴域に入らず、坂に見える。歯が細かくなるのは遅延が長いときになる。
- ハイパスで低域が消える理由を暗記しようとする。引き算が180°反転にあたることを押さえる。
- 遅延をサンプル単位で見ない。聴こえるかどうかはノッチの間隔で決まる。
- カットオフと Q を混同する。極の話は [[極と零点]] に分けた。
