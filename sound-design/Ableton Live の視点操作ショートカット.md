# Ableton Live の視点操作ショートカット

## ひとことで

Live の視点操作は、ズーム（＋－、Z/X、W/H）、追従（Ctrl+Shift+F）、画面の切替（Tab、Ctrl+Alt+英字）、フォーカス（Alt+数字）の4系統に分かれる。

## なぜ効くか / どこで使うか

曲作りで手が止まるのは、たいてい「見たい場所が見えない」ときになる。ズームと追従を指に覚えさせると、マウスを画面の端まで往復する時間が消える。

左手デバイスに割り当てる場合も、この4系統を分けて置くと押し間違いが減る。系統が違うキーが隣り合っていると、ズームのつもりでグリッドが変わる。

## 前提となる知識

| 用語 | 一言の説明 |
|---|---|
| タイムルーラー | 小節番号が並ぶ上の帯。ここの拡大縮小が時間方向のズーム。 |
| ウィンドウズーム | 画面全体の拡大縮小。タイムルーラーのズームとは別物。 |
| 追従（Follow） | 再生が進むと画面が自動でスクロールする状態。 |
| グリッド | 編集の吸着単位。狭くすると細かく、広くすると大づかみになる。 |
| フォーカス | キーボード操作の宛先。Alt+数字で画面ごとに移せる。 |

Windows のキーで書く。Mac は Ctrl が Cmd、Alt が Option になる。

## 本体の解説

### 1. ズーム

| 操作 | キー |
|---|---|
| タイムルーラーの拡大 / 縮小 | `+` / `-` |
| ウィンドウ全体の拡大 / 縮小 | `Ctrl` + `+` / `Ctrl` + `-` |
| 選択範囲へズーム / 戻す | `Z` / `X` |
| 幅に合わせる / 高さに合わせる | `W` / `H` |

`+` / `-` は時間方向だけ、`Ctrl` 付きは画面全体。`Z` は選択した範囲に寄り、`X` で元の倍率に戻る。Arrangement でも Clip View でも効く。

`W` と `H` は、倍率を見失ったときの復帰に使う。

### 2. 追従とスクロール

| 操作 | キー |
|---|---|
| 再生位置に追従する | `Ctrl` + `Shift` + `F` |
| 左右スクロール | `Shift` + スクロール |
| 選択範囲の左右へパン | `Ctrl` + `Alt` + ドラッグ |

追従は、長い曲を流しながら別の場所を触ると外れる。戻すときに `Ctrl` + `Shift` + `F` を押す。

### 3. 画面の切替

| 操作 | キー |
|---|---|
| Session / Arrangement | `Tab` |
| Device View / Clip View | `Shift` + `Tab` か `F12` |
| ブラウザ | `Ctrl` + `Alt` + `B` |
| Overview（全体の俯瞰） | `Ctrl` + `Alt` + `O` |
| In/Out、Sends、ミキサー | `Ctrl` + `Alt` + `I` / `S` / `M` |
| Clip View / Device View の表示切替 | `Ctrl` + `Alt` + `3` / `4` |
| フルスクリーン | `F11` |
| Info View | `Shift` + `?` |

`Ctrl` + `Alt` の列は、画面の一部を出し入れする系統になる。押すたびに表示が反転するので、状態を覚えるより「見たいものを呼ぶ」と考えるほうが早い。

### 4. フォーカスの移動

| 操作 | キー |
|---|---|
| Control Bar | `Alt` + `0` |
| Session View | `Alt` + `1` |
| Arrangement View | `Alt` + `2` |
| Clip View | `Alt` + `3` |
| Device View | `Alt` + `4` |
| Browser | `Alt` + `5` |
| Groove Pool | `Alt` + `6` |
| 選択クリップのパネル | `Alt` + `8` |

マウスを使わずに画面を渡れる。`Tab` での切替と違い、フォーカスを移すだけで表示は保つ。

### 5. グリッド

| 操作 | キー |
|---|---|
| 狭くする | `Ctrl` + `1` |
| 広くする | `Ctrl` + `2` |
| 3連符グリッド | `Ctrl` + `3` |
| スナップのオン / オフ | `Ctrl` + `4` |
| 固定 / ズーム適応の切替 | `Ctrl` + `5` |
| 描画モード | `B` |
| ドラッグ中のスナップを一時解除 | `Alt` を押しながらドラッグ |

`Ctrl` + `1` と `Ctrl` + `2` は、押し間違えると編集の刻みが別物になる。ズームの `+` / `-` と指の位置が近いと事故が起きやすい。

### 6. トラックの高さ

| 操作 | キー |
|---|---|
| 選択トラックやクリップの高さ | `Alt` + `+` / `Alt` + `-` |
| 折り畳み / 展開 | `U` |

`Alt` + `+` / `-` は高さ、素の `+` / `-` は時間方向。同じ記号でも修飾キーで意味が変わる。

## 具体例・コード

左手デバイス（Razer Tartarus Pro）に割り当てる例。

系統を層で分けるのが肝になる。

- 通常の層: `+` / `-`（ズーム）、`Ctrl` + `Shift` + `F`（追従）、`Z` / `X`（選択ズームと復帰）、`Tab`
- HyperShift の層: `Ctrl` + `1` / `Ctrl` + `2`（グリッド）、`Ctrl` + `E`（分割）、`Delete`
- 修飾キー専用: 左下に `Ctrl` / `Shift` / `Alt`
- コピー系: `Ctrl` + `C` / `X` / `V` を同じ列に並べ、`Delete` は離す

押し間違いが多いグリッドとコピー系は、日常の層から外して HyperShift 側に置く。めったに押さない操作ほど、誤爆したときの被害が大きい。

`+` / `-` の代わりに `Z` / `X` を置く手もある。選択に寄って戻るだけなので、間違えても見失うだけで済む。

## つまずきポイント

- 「`+` と `-` で画面全体が拡大される」は間違い。時間方向だけなら `+` / `-`、画面全体は `Ctrl` + `+` / `-`。
- 「`Z` は拡大専用」は間違い。`X` で元の倍率に戻る。セットで覚える。
- 「追従は一度オンにすれば保たれる」は間違い。別の場所を触ると外れる。`Ctrl` + `Shift` + `F` で戻す。
- 「`Alt` + `+` / `-` も時間方向のズームだ」は間違い。こちらはトラックやクリップの高さになる。
- 「`Ctrl` + `1` はズームの拡大だ」は間違い。グリッドを狭くする操作で、時間軸のズームではない。
- 「グリッド変更は元に戻しやすい」は間違い。刻みが変わったことに気づかず編集すると、後から直すのが面倒になる。
