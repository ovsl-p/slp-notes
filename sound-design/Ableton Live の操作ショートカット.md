# Ableton Live の操作ショートカット

## ひとことで

視点と打ち込みの外側にある操作を、トランスポート、トラック、デバイス、ブラウザ、コンピング、バウンス、一時ラッチ、コンピュータ MIDI キーボードの8つに分けて覚える。

## なぜ効くか / どこで使うか

曲を組む流れは、聴く、止める、録る、音を足す、音色を選ぶ、まとめる、の繰り返しになる。この流れの各段にキーがあると、マウスでメニューを開く回数が減る。

特に効くのは、止めた位置から続きを聴く `Shift` + `Space`、選択の終わりで止める `Ctrl` + `Space`、プラグイン画面の一括表示、テイクの差し替えになる。

## 前提となる知識

| 用語 | 一言の説明 |
|---|---|
| アレンジメント | 曲を左から右へ並べる画面。録音の置き場にもなる。 |
| セッション | クリップを縦に並べて鳴らす画面。 |
| テイクレーン | 同じ場所に重ねた録音を、あとから選んで使う仕組み。 |
| バウンス | トラックや選択範囲を、音声ファイルとして新しいトラックに書き出すこと。 |
| モーメンタリラッチ | キーを長押ししている間だけ、切り替えを有効にする使い方。 |

Windows のキーで書く。Mac は Ctrl が Cmd、Alt が Option になるが、例外がある。選択範囲の終わりで止める `Ctrl` + `Space` は `Option` + `Space` になる。記号キーは US 配列の表記で、JIS 配列では位置が変わる。

## 本体の解説

### 1. トランスポートと録音

| 操作 | キー |
|---|---|
| 再生 / 停止 | `Space` |
| 止めた位置から続きを再生 | `Shift` + `Space` |
| 選択範囲の終わりで停止 | `Ctrl` + `Space` |
| 録音 | `F9` |
| アレンジで録音をアーム | `Shift` + `F9` |
| セッションに録音 | `Ctrl` + `Shift` + `F9` |
| セッションからアレンジへ戻る | `F10` |
| メトロノーム | `O` |
| 1〜8番トラックのオン / オフ | `F1` 〜 `F8` |

`Space` は、アレンジメントで時間範囲を選んでいると、その範囲の再生になる。曲全体を流したいときは、先に選択を解除する。

### 2. トラック

| 操作 | キー |
|---|---|
| オーディオ / MIDI / リターントラックを追加 | `Ctrl` + `T` / `Ctrl` + `Shift` + `T` / `Ctrl` + `Alt` + `T` |
| グループ化 / 解除 | `Ctrl` + `G` / `Ctrl` + `Shift` + `G` |
| 選択トラックをアーム | `C` |
| 選択トラックをソロ | `S` |
| 選択トラックのオン / オフ | `0` |
| トラック名の変更 | `Ctrl` + `R` |
| フリーズ / 解除 | `Ctrl` + `Alt` + `Shift` + `F` |
| グループの開閉 | `U` |
| リターントラックの表示切替 | `Ctrl` + `Alt` + `R` |

### 3. デバイス

| 操作 | キー |
|---|---|
| ホットスワップ | `Q` |
| ブラウザで選んだデバイスを読み込む | `Enter` |
| A/B 比較（状態の切替） | `P` |
| パラメータを既定値に戻す | `Delete` かダブルクリック |
| プラグイン画面の一括表示 / 非表示 | `Ctrl` + `Alt` + `P` |
| デバイスのグループ化 / 解除 | `Ctrl` + `G` / `Ctrl` + `Shift` + `G` |

`P` は、いじる前といじった後を行き来するときに使う。音色を作るときの戻り先として便利。

### 4. ブラウザ

| 操作 | キー |
|---|---|
| 検索 | `Ctrl` + `F` |
| 選択項目をロード | `Enter` |
| 選択項目を試聴 | `Shift` + `Enter` か `→` |
| フォルダの開閉 | `→` / `←` |
| 一覧の上下移動 | `↑` / `↓` |
| 履歴を戻る / 進む | `Ctrl` + `[` / `Ctrl` + `]` |
| フィルタ表示の切替 | `Ctrl` + `Alt` + `G` |
| タグエディタの表示切替 | `Ctrl` + `Shift` + `E` |
| 類似ファイルの検索 | `Ctrl` + `Shift` + `F` |

### 5. コンピング（テイクの選択）

| 操作 | キー |
|---|---|
| テイクレーンの表示切替 | `Ctrl` + `Alt` + `U` |
| 選択した範囲をメインのレーンに採用 | `Enter` |
| 選択テイクを試聴 | `T` |
| テイクレーンを追加 | `Shift` + `Alt` + `T` |
| メインに置くテイクを次 / 前へ | `Ctrl` + `↑` / `↓` |

### 6. バウンス

| 操作 | キー |
|---|---|
| 新しいトラックへバウンス | `Ctrl` + `B` |
| バウンスした音声を貼る | `Ctrl` + `Alt` + `V` |

`Ctrl` + `B` は、選択範囲かトラック単位で音声を作る。外部プラグインの音を固定したいときにも使う。

### 7. モーメンタリラッチ

次のキーは、500ms ほど長押しすると一時的な切替になる。離すと元に戻る。

- `A` : アレンジのオートメーションモード
- `B` : 描画モード
- `S` : 選択トラックのソロ
- `Z` : アレンジの選択範囲へのズーム
- `F1` 〜 `F8` : 1〜8番トラックのオン / オフ
- `Tab` : セッション / アレンジの切替

一瞬だけミュートを外して確かめる、といった使い方ができる。`Options.txt` の `-DisableHotKeyLatching` で無効にできる。

### 8. コンピュータ MIDI キーボード

| 操作 | キー |
|---|---|
| オン / オフ | `M` |
| オクターブを上下 | `X` / `Z` |
| 入力ベロシティを変える | `C` / `V` |
| MIDI マップモード | `Ctrl` + `M` |
| キーマップモード | `Ctrl` + `K` |

有効にしている間も、`Shift` を足せば単独キーのショートカットが効く。`Shift` + `S` でソロ、など。`C` / `V` のどちらが上げる側かは、公式の表に書かれていない。第三者の解説では `C` が下げ、`V` が上げるとされる。

## 具体例・コード

曲を仕上げる流れに沿って並べると、次の順になる。

1. `Ctrl` + `T` と `Ctrl` + `Shift` + `T` でトラックを足す
2. `Ctrl` + `F` でブラウザを検索し、`Shift` + `Enter` で試聴、`Enter` でロード
3. `F9` で録り、`Shift` + `Space` で止めた位置から聴き直す
4. `Ctrl` + `Alt` + `U` でテイクを開き、`T` で試聴、`Ctrl` + `↑` で差し替える
5. `Q` と `P` で音色を差し替え、前後を比べる
6. `Ctrl` + `B` で書き出し、`Ctrl` + `Alt` + `V` で貼る

左手デバイスに寄せるなら、`Space`、`Shift` + `Space`、`F9`、`Ctrl` + `B`、`Ctrl` + `F` の5つを単独キーで押せる位置に置くと、作業の流れが切れにくい。

## つまずきポイント

- 「`Space` はいつも最初から再生する」は間違い。アレンジメントで時間範囲を選んでいれば、その範囲の再生になる。
- 「`Ctrl` + `Space` は停止だ」は間違い。選択範囲の終わりで止まる操作で、通常の停止は `Space`。
- 「`Ctrl` + `G` はいつもトラックのグループ」は間違い。ノートエディタでは同時発音、デバイス画面ではデバイスのグループになる。
- 「`Ctrl` + `B` はプロジェクト全体の書き出し」は間違い。選択範囲かトラックを音声にする操作で、全体の書き出しは `Ctrl` + `Shift` + `R`（Export Audio/Video）。
- 「モーメンタリラッチは設定で有効にするもの」は間違い。既定で使え、`Options.txt` で止められる。
- 「コンピュータ MIDI キーボードを出すと、他のショートカットは効かない」は間違い。`Shift` を足せば効く。
