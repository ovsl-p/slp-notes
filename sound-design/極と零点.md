# 極と零点

## ひとことで

極は共鳴の中心、零点は消える点。この2つの位置だけで、フィルタの性格がほぼ決まる。

## なぜ効くか / どこで使うか

シンセのフィルターのノブ（カットオフ、レゾナンス）が内部で何を動かしているかが分かる。プラグインの設計、不安定になる原因、EQ のカーブの作り方まで、全部この2語で説明できる。

- **レゾナンスを上げると「ピー」と鳴る** → 極が単位円に近づいている
- **カットオフを動かすと曲がり位置が動く** → 極の角度が回っている
- **ノッチ（帯域除去）は零点を単位円上に置いたもの**

## 前提となる知識

| 知っておくこと | なぜ必要か |
| --- | --- |
| 複素数と極座標 | 極は複素平面上の点。角度と半径で語る |
| 単位円 | 半径1の円。ここを越えると発散する境界線 |
| z変換の基礎 | `H(z) = B(z)/A(z)` の分母の根が極、分子の根が零点 |
| フィードバック | IIR の極は「過去の出力を使う」ことから生まれる |
| Q の意味 | 極の半径と対応する「鋭さ」の指標 |

複素数・複素平面・極形式が不安なら [[複素数と極座標]] を先に読むと楽になる。

## 本体の解説

### 極（pole）って何？

**極は「フィルタが共鳴する中心」**。数学的には `H(z) = B(z)/A(z)` の**分母が 0 になる点**で、そこでゲインが理論上無限大になる。直感では「**フィードバックが作る反響の閉じ込め**」。

- 極には**角度**と**半径**がある（複素平面上の位置）
- **角度** → 共鳴する周波数（`f = θ·fs/2π`）
- **半径** → 共鳴の鋭さ。**1 に近いほど鋭く、長く響く**

シンセのフィルターでレゾナンスを上げると「ピー」と鳴る、あれが**極を単位円（半径1）に近づけている状態**。実測（LPF fc=1kHz）:

| Q | ピーク | 極の半径 | 聞こえ方 |
| --- | --- | --- | --- |
| 0.71 | -0.26 dB（ピークなし） | 0.912 | 素直なローパス |
| 5 | +14.0 dB @ 990Hz | 0.987 | レゾナンスが出る |
| 20 | +26.0 dB @ 1kHz | 0.997 | 笛のように鳴る |

半径が **1 を超えると発散**（不安定）。だから IIR では極の位置が常に問題になる。FIR は分母が 1（＝極がない。全部 z=0 の原点にある）ので、**不安定になりようがない**。

ブランコのたとえが近い。押すタイミングが合うと（共鳴周波数）どんどん大きくなり、摩擦が小さい（極が単位円に近い）ほど大きく響く。押しすぎると制御不能（発散）。

### カットオフと Q は、極のどこを動かすノブか

よくある誤解が「カットオフを動かす＝可聴域外のノッチの Q を変えている」。実際は**別々のつまみ**で、動く場所が違う。

実測（2次ローパス、零点と極の位置を計算したもの）:

**カットオフを動かす（Q=0.707 固定）**

| fc | 極の角度 | 極の半径 | 零点 |
| --- | --- | --- | --- |
| 200Hz | 1.06° | 0.982 | -1.0（固定） |
| 1kHz | 5.32° | 0.912 | -1.0（固定） |
| 5kHz | 28.5° | 0.631 | -1.0（固定） |
| 10kHz | 69.3° | 0.434 | -1.0（固定） |

**Q を動かす（fc=1kHz 固定）**

| Q | 極の角度 | 極の半径 |
| --- | --- | --- |
| 0.71 | 5.32° | 0.912 |
| 5 | 7.46° | 0.987 |
| 20 | 7.50° | 0.997 |

読み取れること:

- **カットオフ = 極の角度を回すノブ**（＝共鳴する周波数・曲がり始める位置を動かす）。半径も副次的に動く
- **Q = 極の半径を外に出すノブ**（＝鋭さを変える）。角度はほぼ動かない
- **零点は z = −1（24kHz = ナイキスト）に固定**。ローパスの「高域が落ち続ける」性質はこの零点が作っていて、**カットオフを動かしても零点は動かない**

つまりローパスは「ノッチを可聴域の外に置いているフィルタ」ではなく、**極で曲がりを作り、ナイキストの零点で落とし続ける**構造。ノッチフィルタ（帯域除去）はまた別の設計で、零点を単位円上に置いたもの。

実務では、カットオフを動かすときは**係数を再計算している**（＝極を動かしている）。急に動かすとフィルタの内部状態が飛んでクリックが出るので、**パラメータは補間して滑らかに動かす**。

### 「減衰」には2種類ある

極の半径を「音が残りやすい」と読むと、**200Hz のローパスなのに高域がゴッソリ削れる**のと矛盾して見える。実は別の軸の話をしている。

- **時間方向の減衰**（極の半径 r）: 入力が止まったあと、フィルタが**自分で鳴り続ける長さ**（インパルス応答の寿命）
- **周波数方向の減衰**（ゲイン）: その周波数を**どれだけ通すか**。これは「周波数の点 `e^{jω}` が極からどれだけ離れているか」で決まる

実測（2次ローパス、Q=0.707、48kHz）:

| fc | 極の角度 | 極の半径 | 鳴り続ける長さ(-60dB) | 1kHz | 10kHz |
| --- | --- | --- | --- | --- | --- |
| 200Hz | 1.06° | 0.982 | **7.8 ms** | -28.0 dB | -70.7 dB |
| 1kHz | 5.32° | 0.912 | 1.6 ms | -3.0 dB | -42.7 dB |
| 5kHz | 28.5° | 0.631 | 0.3 ms | -0.0 dB | -14.3 dB |

200Hz のローパスは半径が一番大きい（＝一番長く鳴る）のに、10kHz は -70.7dB でほぼ通さない。**長く鳴るのは 141Hz 付近の低い音**であって、高域ではない。

理由は距離で説明できる。極は角度1.06°（ほぼ実軸上）にあるので、10kHz に対応する単位円上の点（角度75°）は極から遠い。遠い＝ゲインが小さい。だから高域は削られる。逆に 200Hz 付近の点は極に近いので持ち上がり、しかも半径が1に近いので**その周波数だけ長く響く**。

つまり:

- 半径は「**どのくらい長く鳴るか**」（時間）
- 角度は「**どこで鳴るか**」（周波数）
- 発散（r > 1）は「入力がなくても増え続ける」状態で、普通の音量変化とは別の話

### 零点（zero）とノッチ

極が「盛り上がる点」なら、**零点は「消える点」**。`H(z)` の分子が 0 になる場所で、そこではゲインが 0 になる。

- **零点が単位円の上にある** → その角度の周波数が完全に消える（ノッチフィルタ、帯域除去）
- **零点が単位円の外／内にある** → 影響は弱まり、カーブが緩やかに曲がるだけ
- **ローパスの零点は z = −1（ナイキスト）に固定** → だから高域が落ち続ける。カットオフを動かしても零点は動かない

「ローパスもノッチの一種」と混同しやすいが、**ローパスは極で曲がりを作り、ナイキストの零点で落とす**構造。ノッチは零点を可聴域内に置いた別物。

### 安定性は極で決まる

極の半径が 1 未満なら安定（響きは減衰する）。1 以上だと発散する。IIR が「係数の丸め誤差で壊れうる」と言われるのは、極が単位円のすぐ内側にあるから。詳細は [[FIR と IIR の違い]] の「安定性」の節。

## 具体例・コード

2次ローパスの極を計算する（極は `z² + a1·z + a2 = 0` の根）。

```python
import math, cmath

SR = 48000.0
fc, Q = 1000.0, 1 / math.sqrt(2)

w0 = 2 * math.pi * fc / SR
alpha = math.sin(w0) / (2 * Q)
a0 = 1 + alpha
a1 = (-2 * math.cos(w0)) / a0
a2 = (1 - alpha) / a0

disc = cmath.sqrt(a1 * a1 - 4 * a2)
pole = (-a1 + disc) / 2
print("極の半径 =", abs(pole), " 角度 =", math.degrees(cmath.phase(pole)), "°")
# 半径 0.9116 / 角度 5.32° → 共鳴は 5.32/360*48000 ≒ 709Hz 付近
```

Q を上げると半径が 1 に近づき、ピークが鋭くなる（実測: Q=0.71→0.912 / Q=5→0.987 / Q=20→0.997）。

## つまずきポイント

- **カットオフと Q を同じつまみだと思う**。カットオフは極の角度、Q は極の半径。別物
- **「カットオフを動かす＝ノッチを動かす」と思う**。ローパスの零点はナイキスト固定。動くのは極
- **Q を上げすぎる**。極が単位円に近づき、ゲインが跳ねて発散しやすくなる（固定小数点では特に）
- **極の角度をそのまま周波数だと思う**。`f = θ·fs/2π` の換算が必要。低域では角度がごく小さい
- **ノッチフィルタとローパスを同一視する**。零点の置き場所が違う
