# 極と零点

## ひとことで

極は共鳴の中心、零点は消える点。この2つの位置だけで、フィルタの性格がほぼ決まる。

## なぜ効くか / どこで使うか

シンセのフィルターのノブが内部で何を動かしているかが分かると、プラグインの設計や不安定になる原因、EQ のカーブの作り方が読める。カットオフは極の角度を回す操作、レゾナンスは極の半径を外に出す操作にあたる。ノッチ（帯域除去）は零点を単位円の上に置いたものになる。

## 前提となる知識

| 知っておくこと | なぜ必要か |
| --- | --- |
| 複素数と極座標 | 極は複素平面上の点。角度と半径で語る |
| 単位円 | 半径1の円。ここを越えると発散する境界線 |
| z変換の基礎 | `H(z) = B(z)/A(z)` の分母の根が極、分子の根が零点 |
| フィードバック | IIR の極は「過去の出力を使う」ことから生まれる |
| Q の意味 | 極の半径と対応する「鋭さ」の指標 |

複素数・複素平面・極形式が不安なら [[複素数と極座標]] を先に読むと楽になる。

## 本体の解説

### 極（pole）って何？

`H(z) = B(z)/A(z)` の分母が 0 になる点が極で、そこではゲインが理論上無限大になる。**極はフィルタが共鳴する中心**にあたる。

極は複素平面上の点で、角度が共鳴する周波数、半径が共鳴の鋭さを表す。半径が 1 に近いほど鋭く、長く響く。ブランコを押すタイミングが合うと揺れが大きくなるのと同じで、実際に起きているのは、その周波数の減衰が遅くなることだ。

シンセのフィルターでレゾナンスを上げると「ピー」と鳴るのは、極を単位円（半径1の円）に近づけている状態になる。実測（LPF fc=1kHz）:

| Q | ピーク | 極の半径 | 聞こえ方 |
| --- | --- | --- | --- |
| 0.71 | -0.26 dB（ピークなし） | 0.912 | 素直なローパス |
| 5 | +14.0 dB @ 990Hz | 0.987 | レゾナンスが出る |
| 20 | +26.0 dB @ 1kHz | 0.997 | 笛のように鳴る |

半径が 1 を超えると発散する。IIR で極の位置が常に問題になるのはこのためで、FIR は分母が 1 なので極を持たず、不安定になりようがない。

### カットオフと Q は、極のどこを動かすノブか

カットオフを動かすと極の角度が回り、Q を動かすと極の半径が外に出る。実測（2次ローパス）:

カットオフを動かす（Q=0.707 固定）

| fc | 極の角度 | 極の半径 | 零点 |
| --- | --- | --- | --- |
| 200Hz | 1.06° | 0.982 | -1.0（固定） |
| 1kHz | 5.32° | 0.912 | -1.0（固定） |
| 5kHz | 28.5° | 0.631 | -1.0（固定） |
| 10kHz | 69.3° | 0.434 | -1.0（固定） |

Q を動かす（fc=1kHz 固定）

| Q | 極の角度 | 極の半径 |
| --- | --- | --- |
| 0.71 | 5.32° | 0.912 |
| 5 | 7.46° | 0.987 |
| 20 | 7.50° | 0.997 |

カットオフは共鳴する周波数と曲がり始める位置を動かし、半径も副次的に動かす。Q は鋭さだけを動かし、角度はほぼ変えない。

実務では、カットオフを動かすと係数を再計算することになる。急に動かすとフィルタの内部状態が飛んでクリックが出るので、パラメータは補間して滑らかに動かす。

### 「減衰」には2種類ある

200Hz のローパスは半径が大きい（＝長く鳴る）のに高域をゴッソリ削る。矛盾して見えるが、減衰という言葉が2つのものを指している。

時間方向の減衰は極の半径が決める。入力が止まったあと、フィルタが自分で鳴り続ける長さにあたる。

周波数方向の減衰はゲインのことで、その周波数の点 `e^{jω}`（周波数に対応する単位円上の点）が極からどれだけ離れているかで決まる。

実測（2次ローパス、Q=0.707、48kHz）:

| fc | 極の角度 | 極の半径 | 鳴り続ける長さ(-60dB) | 1kHz | 10kHz |
| --- | --- | --- | --- | --- | --- |
| 200Hz | 1.06° | 0.982 | 7.8 ms | -28.0 dB | -70.7 dB |
| 1kHz | 5.32° | 0.912 | 1.6 ms | -3.0 dB | -42.7 dB |
| 5kHz | 28.5° | 0.631 | 0.3 ms | -0.0 dB | -14.3 dB |

200Hz の極は角度 1.06° でほぼ実軸上にあり、10kHz に対応する点（角度75°）は極から遠い。遠いほどゲインが小さいので高域は削られ、長く鳴るのは極に近い 141Hz 付近の低い音になる。

半径を動かしても、変わるのは極の角度の周波数だけで、離れた周波数はほとんど動かない。零点のない2極の共振器（極の角度30°＝4kHz）で半径だけを動かした実測:

| r | 4kHz（極の周波数） | 8kHz | 12kHz | 20kHz |
| --- | --- | --- | --- | --- |
| 0.5 | 7.3 dB | 3.2 dB | -1.2 dB | -6.0 dB |
| 0.9 | 20.4 dB | 3.4 dB | -3.9 dB | -9.9 dB |
| 0.99 | 40.0 dB | 2.8 dB | -4.7 dB | -10.7 dB |
| 0.999 | 60.0 dB | 2.7 dB | -4.8 dB | -10.8 dB |

**極の角度が鳴る場所を、半径が鳴り続ける長さを決める。**

### 零点（zero）とノッチ

`H(z)` の分子が 0 になる点が零点で、そこではゲインが 0 になる。**零点は消える点**にあたる。

零点が単位円の上にあると、その角度の周波数が完全に消える。単位円の外や内にあると影響は弱まり、カーブが緩やかに曲がるだけになる。

ローパスの零点は z = -1 に固定されている。ここはナイキスト周波数（サンプルレートの半分。48kHz なら24kHz）にあたる。カットオフを動かしてもこの零点は動かないので、高域が落ち続ける性質は変わらない。ノッチフィルタは零点を可聴域の中に置いた別の設計になる。

### 安定性は極で決まる

極の半径が 1 未満なら安定で、響きは減衰する。1 以上だと発散する。IIR が「係数の丸め誤差で壊れうる」と言われるのは、極が単位円のすぐ内側にあるから。詳細は [[FIR と IIR の違い]] の「安定性」の節。

## 具体例・コード

2次ローパスの極を計算する（極は `z² + a1·z + a2 = 0` の根）。

```python
import math, cmath

SR = 48000.0
fc, Q = 1000.0, 1 / math.sqrt(2)

w0 = 2 * math.pi * fc / SR
alpha = math.sin(w0) / (2 * Q)
a0 = 1 + alpha
a1 = (-2 * math.cos(w0)) / a0
a2 = (1 - alpha) / a0

disc = cmath.sqrt(a1 * a1 - 4 * a2)
pole = (-a1 + disc) / 2
print("極の半径 =", abs(pole), " 角度 =", math.degrees(cmath.phase(pole)), "°")
# 半径 0.9116 / 角度 5.32° → 共鳴は 5.32/360*48000 ≒ 709Hz 付近
```

Q を上げると半径が 1 に近づき、ピークが鋭くなる（実測: Q=0.71→0.912 / Q=5→0.987 / Q=20→0.997）。

## つまずきポイント

- カットオフと Q を同じつまみだと思う。カットオフは極の角度、Q は極の半径を動かす。
- カットオフを動かすとノッチが動くと思う。動くのは極で、零点は -1 のまま。
- Q を上げすぎる。極が単位円に近づいてゲインが跳ね、固定小数点では発散しやすい。
- 極の角度をそのまま周波数だと思う。`f = θ·fs/2π` の換算が要る。
- ノッチフィルタとローパスを同一視する。零点の置き場所が違う。
