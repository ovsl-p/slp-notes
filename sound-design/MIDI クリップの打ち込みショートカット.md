# MIDI クリップの打ち込みショートカット

## ひとことで

打ち込みは、選択と移動、分割と結合、ベロシティ、クオンタイズ、グリッド、表示の6系統で覚えると手が止まらない。

## なぜ効くか / どこで使うか

MIDI を打つ作業は、同じ操作の繰り返しになる。1回あたりは数秒でも、フレーズを何十回も直すと差が出る。

特に効くのは、選択の拡張（`Ctrl` + `A`、`Ctrl` + `Shift` + `A`）、ベロシティの一括変更、分割の3つ。マウスだと1ノートずつ触ることになる。

## 前提となる知識

| 用語 | 一言の説明 |
|---|---|
| ノートエディタ | Clip View の中で MIDI ノートを並べる画面。 |
| ベロシティ | ノートの強さ。0〜127 の数値で入る。 |
| クオンタイズ | ノートの位置をグリッドに揃える処理。 |
| ノートフィルタ | 音程やベロシティの範囲でノートを絞り込む機能。 |
| MIDI ツール | Live 12 のノート編集ツール。設定をまとめて適用できる。 |

Windows のキーで書く。Mac は Ctrl が Cmd、Alt が Option になる。

## 本体の解説

### 1. 選択と移動

| 操作 | キー |
|---|---|
| 全ノートを選択 | `Ctrl` + `A` |
| 選択を反転 | `Ctrl` + `Shift` + `A` |
| 次のノート / 前のノート | `Alt` + `↑` / `↓` |
| 同じ音程の次のノート / 前のノート | `Alt` + `→` / `←` |
| ノートを移動 | 矢印キー（左右はグリッド単位、上下は半音） |
| 複数選択 | `Shift` + クリック、`Ctrl` + クリック |

`Alt` + 矢印はノートを動かさずに選択だけを移す。広い範囲から1つずつ確かめたいときに使う。

### 2. 分割と結合

| 操作 | キー |
|---|---|
| グリッドで分割、または選択範囲の端で分割 | `Ctrl` + `E` |
| 1つずつ刻む | `Ctrl` + `E` を押しながら上下ドラッグ |
| 2つずつ刻む | `Ctrl` + `Shift` + `E` を押しながら上下ドラッグ |
| 任意の位置で分割 | `E` を押しながらクリック |
| ノートを結合 | `Ctrl` + `J` |
| ノートを時間範囲に合わせる | `Ctrl` + `Alt` + `J` |

`Ctrl` + `E` は、選択範囲があるときはその端で切り、ないときはグリッドで切る。同じキーで2通りになるので、先に範囲を選ぶかどうかで結果が変わる。

### 3. コピーと複製

| 操作 | キー |
|---|---|
| コピー | `Ctrl` + `C` |
| 切り取り | `Ctrl` + `X` |
| 貼り付け | `Ctrl` + `V` |
| 複製 | `Ctrl` + `D` |
| ドラッグでコピー | `Ctrl` を押しながらドラッグ |
| 削除 | `Delete` |
| 元に戻す / やり直す | `Ctrl` + `Z` / `Ctrl` + `Y` |

打ち込みでは `Ctrl` + `D` が主力になる。選択したノートを、後ろへずらして複製する。

### 4. ベロシティと確率

| 操作 | キー |
|---|---|
| 選択ノートのベロシティを上げ下げ | `Ctrl` + `↑` / `↓` |
| ベロシティのばらつきを変える | `Ctrl` + `Shift` + `↑` / `↓` |
| 発音確率（チャンス）を変える | `Ctrl` + `Alt` + `↑` / `↓` |
| 数値で指定 | 0〜127 を入力して `Enter` |
| エディタ上でベロシティを変える | `Alt` を押しながら上下ドラッグ |

ベロシティの一括変更は、フレーズ全体の表情を決めるときに使う。確率は、ループに揺らぎを入れたいときの機能。

### 5. クオンタイズとグループ

| 操作 | キー |
|---|---|
| クオンタイズ | `Ctrl` + `U` |
| クオンタイズの設定 | `Ctrl` + `Shift` + `U` |
| ノートをグループ化（同時発音） | `Ctrl` + `G` |
| グループを解除 | `Ctrl` + `Shift` + `G` |
| MIDI ツールの設定を適用 | `Ctrl` + `Enter` |

グループ化は、和音を1つの単位として動かしたいときに使う。バラバラに動くと和音が崩れる場面で効く。

### 6. グリッドと描画

| 操作 | キー |
|---|---|
| グリッドを狭く / 広く | `Ctrl` + `1` / `Ctrl` + `2` |
| 3連符グリッド | `Ctrl` + `3` |
| スナップのオン / オフ | `Ctrl` + `4` |
| 固定 / ズーム適応の切替 | `Ctrl` + `5` |
| 描画モード | `B` |
| ドラッグ中のスナップを一時解除 | `Alt` を押しながらドラッグ |

### 7. 表示と音階

| 操作 | キー |
|---|---|
| 音階をハイライト | `K` |
| ノートフィルタの表示切替 | `Ctrl` + `Shift` + `F` |
| クリップビューを大きく | `Ctrl` + `Alt` + `E` |
| 縦スクロール / 細かく | `Page Up` `Page Down` / `Shift` 併用 |
| 横スクロール | `Ctrl` + `Page Up` / `Page Down` |
| 選択範囲へズーム / 戻す | `Z` / `X` |
| 横方向のズーム | `+` / `-` |
| 幅 / 高さに合わせる | `W` / `H` |
| コンピュータ MIDI キーボード | `Ctrl` + `Shift` + `K` |

`K` で音階がハイライトされるので、スケールから外れた音が目で分かる。

## 具体例・コード

左手デバイス（Razer Tartarus Pro）に寄せるなら、こんな分け方になる。

- 通常の層: `Ctrl` + `D`（複製）、`Delete`、`B`（描画）、`Ctrl` + `1` / `2`（グリッド）、`K`（音階）
- HyperShift の層: `Ctrl` + `E`（分割）、`Ctrl` + `J`（結合）、`Ctrl` + `U`（クオンタイズ）、`Ctrl` + `G`（グループ）
- 修飾キー専用: 左下に `Ctrl` / `Shift` / `Alt`
- 親指側: `Ctrl` + `Z` / `Ctrl` + `Y`（戻す / やり直す）

打ち込みで一番押すのは `Ctrl` + `D` と `Delete`。この2つは修飾キーと組み合わせずに単独で押せる位置に置くと速い。

`Ctrl` + `E` は、範囲選択の有無で結果が変わる。誤爆するとノートが刻まれるので、HyperShift 側に置く。

## つまずきポイント

- 「`Ctrl` + `E` はいつも同じように分割する」は間違い。選択範囲の有無で切る位置が変わる。
- 「`Ctrl` + `↑` / `↓` はノートを半音動かす」は間違い。こちらはベロシティで、移動は素の矢印キー。
- 「`Alt` + 矢印はノートを動かす」は間違い。選択を次のノートへ移すだけで、位置は変わらない。
- 「`Ctrl` + `D` はコピーだけ」は間違い。複製して、後ろへずらした状態まで作る。
- 「`Ctrl` + `G` はトラックのグループ」は間違い。ノートエディタでは、選択ノートの同時発音グループになる。
- 「グループ化は見た目だけを変える」は間違い。動かすと1つの単位として動く。
