# 複素数と極座標

## ひとことで

複素数は「回転と拡大」を1つの数で表す道具。極座標は「どれだけ離れて、どれだけ回ったか」で位置を書く方法。

## なぜ効くか / どこで使うか

フィルタの「極」は複素平面上の点で、その位置が音の性質を決める。極座標が読めないと、この対応が一生つながらない。

- **角度** → 振動の速さ（どの高さで共鳴するか）
- **半径** → 減衰の具合（すぐ消えるか、長く残るか）

音に限らず、振動・波・回転が出てくる話は全部この形で書ける。フーリエ変換もサンプリングも、根っこはここ。

## 前提となる知識

| 知っておくこと | なぜ必要か |
| --- | --- |
| 三角関数（sin / cos）とラジアン | 極形式が `r(cosθ + i·sinθ)` で書かれる |
| 平方根 | 半径 `r = √(x² + y²)` と、2次方程式の解に使う |
| 2次方程式の解の公式 | 極は「分母 = 0」の方程式の根。判別式が負だと複素根になる |
| xy 座標 | 複素平面はただの平面。横が実部、縦が虚部 |

## 本体の解説

### 1. 虚数単位 i は「回転の記号」

`i² = -1` を満たす数を虚数単位と呼ぶ。よく「存在しない数」と説明されるが、**「90度回す操作」を表す記号**だと思うほうが実用的。

- 1 に i を掛ける → 90度回る
- もう一度 i を掛ける → さらに90度回って、`i² = -1`（180度 = 反転）

掛け算が回転になる、というのがこの先の全部の土台。

### 2. 複素平面

複素数 `z = x + i·y` は、平面上の点 `(x, y)` として描ける。

- 横軸 = 実部 x
- 縦軸 = 虚部 y

足し算は**ベクトルの足し算**（平行四辺形）。掛け算は**回転と拡大**（後述）。この2つの性質が違うので、混ぜないこと。

### 3. 極形式：距離と角度で書く

同じ点を「原点からどれだけ離れて、どれだけ回ったか」で書ける。

```
z = r (cos θ + i·sin θ)
r = |z| = √(x² + y²)        ← 原点からの距離（絶対値）
θ = atan2(y, x)             ← 正の実軸からの角度（偏角）
```

これが **極形式**。`x + iy` の形を「直交形式」、`r(cosθ + i sinθ)` を「極形式」と呼ぶ。同じ点の2通りの書き方。

フィルタで使うのは極形式のほう。**r と θ がそのまま「減衰」と「振動の速さ」になる**から。

### 4. オイラーの公式

`cos θ + i·sin θ` は `e^{iθ}` と書ける（オイラーの公式）。つまり

```
z = r · e^{iθ}
```

`e^{iθ}` は**半径1の円（単位円）の上を角度 θ の位置にある点**。θ を増やすと円を回る。だから「複素数を掛ける＝回す」が自然に説明できる。

音の話で `z = e^{jω}`（j は i と同じ）が出てくるのは、**周波数 ω を単位円上の回転に置き換えている**から。

### 5. 掛け算は「距離は掛け算、角度は足し算」

極形式の最大の利点。

```
r1·e^{iθ1} × r2·e^{iθ2} = (r1·r2)·e^{i(θ1+θ2)}
```

- 絶対値（距離）は掛け算
- 偏角（角度）は足し算

だから「回転して伸び縮みする操作」が1回の掛け算で書ける。フィルタの周波数応答が `H(z)` の掛け算で表せるのもこれ。

### 6. 2次方程式の複素根

フィルタの極は `A(z) = 0` の根、つまり2次方程式の解。

```
z² + a·z + b = 0
z = (-a ± √(a² - 4b)) / 2
```

判別式 `a² - 4b` が**負**のとき、√ の中が負になり、答えは複素数になる。このとき根は必ず**共役のペア**になる。

```
z = r·e^{+iθ} と z = r·e^{-iθ}
```

共役というのは「実部が同じで虚部の符号だけ違う」点で、複素平面では**実軸に対して線対称**。フィルタの極は実係数なので、複素根は必ずこのペアで出てくる。

### 7. 半径と角度が音になる

極 `r·e^{iθ}` の意味:

- **θ（角度）** = その点が円を回る速さ = **振動の周波数**。1周（2π）で `fs` サンプルなので、`f = θ/(2π)·fs`
- **r（半径）** = 1回転するごとにどれだけ残るか = **減衰**。`r < 1` なら減衰、`r = 1` なら減衰しない（発振の境界）、`r > 1` なら増える

だから「極が単位円に近い＝長く響く」「極が円の外＝発散」になる。単位円は**「減衰しないかどうかの境界線」**。

注意: 角度と実際の共鳴周波数は、Q が高いときはほぼ一致するが、Q が低いと山そのものが消えるので「周波数」として読めなくなる。

## 具体例・コード

2次方程式を解いて、半径と角度を出し、周波数に換算する。

```python
import math, cmath

# z^2 + a*z + b = 0  （判別式が負 → 複素根）
a, b = -1.8, 0.9
disc = cmath.sqrt(a*a - 4*b)
z1 = (-a + disc) / 2
z2 = (-a - disc) / 2

print(z1, z2)                     # 共役ペア
r = abs(z1)
theta = math.atan2(z1.imag, z1.real)

fs = 48000
print("半径 r =", round(r, 4))          # 1 に近いほど減衰しにくい
print("角度 θ =", round(math.degrees(theta), 2), "度")
print("周波数に換算 =", round(theta / (2*math.pi) * fs), "Hz")
# 極形式でも書ける
print("極形式:", round(r, 4), "* e^{i", round(math.degrees(theta),1), "度}")
```

出力は半径 0.9487、角度 18.43度、周波数 2458Hz。この点が極なら、約2.5kHzで軽く響き、ゆっくり減衰するフィルタになる。

## つまずきポイント

- **i を「存在しない数」と覚える**。存在するかどうかではなく「回転を表す記号」として使うもの。`i² = -1` はその定義
- **角度を度で計算する**。プログラムの三角関数は**ラジアン**。`math.degrees` で表示だけ度にする
- **絶対値と実部を混同する**。`|z|` は原点からの距離で、実部 x とは違う
- **共役の意味を忘れる**。実係数のフィルタでは複素根が必ずペアで出る。片方だけ見てもう片方を無視しない
- **r = 1 を「普通の状態」と思う**。減衰しない＝発振の境界。設計では r を 1 より十分内側に置く
- **θ から周波数への換算を忘れる**。θ は角度、f は Hz。`f = θ/(2π)·fs` を挟む
