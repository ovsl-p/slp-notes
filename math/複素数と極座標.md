# 複素数と極座標

## ひとことで

複素数は「回転と拡大」を1つの数で表す道具。極座標は「どれだけ離れて、どれだけ回ったか」で位置を書く方法。

## なぜ効くか / どこで使うか

フィルタの極は複素平面上の点で、その位置が音の性質を決める。角度が振動の速さを、半径が減衰の具合を表すので、極座標が読めると音の見当がつく。

## 前提となる知識

| 知っておくこと | なぜ必要か |
| --- | --- |
| 三角関数（sin / cos）とラジアン | 極形式が `r(cosθ + i·sinθ)` で書かれる |
| 平方根 | 半径 `r = √(x² + y²)` と、2次方程式の解に使う |
| 2次方程式の解の公式 | 極は分母が0になる方程式の根。判別式が負だと複素根になる |
| xy 座標 | 複素平面はただの平面。横が実部、縦が虚部 |

## 本体の解説

### 1. 虚数単位 i は「回転の記号」

`i² = -1` を満たす数を虚数単位と呼ぶ。よく「存在しない数」と説明されるが、ここで使うのは**90度回す操作を表す記号**としての i だ。

1 に i を掛けると90度回り、もう一度掛けるとさらに90度回って -1 になる。`i² = -1` はこの2回転を式にしたものになる。

### 2. 複素平面

複素数 `z = x + i·y` は平面上の点 `(x, y)` として描ける。横軸が実部 x、縦軸が虚部 y にあたる。

足し算はベクトルの足し算になり、掛け算は回転と拡大になる。この2つは別の操作なので、混ぜて読まないようにする。

### 3. 極形式：距離と角度で書く

同じ点を、原点からの距離と回った角度で書ける。

```
z = r (cos θ + i·sin θ)
r = |z| = √(x² + y²)        ← 原点からの距離（絶対値）
θ = atan2(y, x)             ← 正の実軸からの角度（偏角）
```

この書き方を極形式と呼び、`x + iy` の形は直交形式と呼ぶ。

フィルタで使うのは極形式のほうで、r が減衰、θ が振動の速さにあたる。

### 4. オイラーの公式

`cos θ + i·sin θ` は `e^{iθ}` と書ける。これをオイラーの公式という。

```
z = r · e^{iθ}
```

`e^{iθ}` は単位円（半径1の円）の上で角度 θ の位置にある点で、θ を増やすと円を回る。

音の話で出てくる `z = e^{jω}` の j は i と同じもの。ω は角周波数で、1サンプルあたりに回る角度（2πf/fs）を表す。

### 5. 掛け算は「距離は掛け算、角度は足し算」

```
r1·e^{iθ1} × r2·e^{iθ2} = (r1·r2)·e^{i(θ1+θ2)}
```

絶対値どうしが掛け算になり、偏角どうしが足し算になる。回転して伸び縮みする操作が1回の掛け算で書けるので、フィルタの周波数応答も `H(z)` の掛け算で表せる。

### 6. 2次方程式の複素根

フィルタの極は `A(z)` が 0 になる点で、2次方程式の解にあたる。

```
z² + a·z + b = 0
z = (-a ± √(a² - 4b)) / 2
```

判別式 `a² - 4b` が負のとき、√ の中が負になって答えは複素数になり、根は共役のペアになる。

```
z = r·e^{+iθ} と z = r·e^{-iθ}
```

共役とは実部が同じで虚部の符号だけ違う点のことで、複素平面では実軸に対して線対称に並ぶ。フィルタの係数は実数なので、複素根はこのペアで出る。

### 7. 半径と角度が音になる

極 `r·e^{iθ}` の角度は円を回る速さを表し、1周が `fs` サンプルなので `f = θ/(2π)·fs` の周波数に対応する。半径は1回転するごとにどれだけ残るかを表し、1 より小さければ減衰し、1 より大きければ増えていく。

**極の角度が周波数を、半径が減衰を決める。**

角度と実際の共鳴周波数は、Q が高いときはほぼ一致する。Q（共鳴の鋭さを表す設計値）が低いと山そのものが消えるので、角度を周波数として読めなくなる。→ [[極と零点]]

### 図解：掛け算は回転

![[assets/math/complex-rotation.svg]]

図の左は単位円上を90度ずつ進む様子、中央は同じ点を距離 r と角度 theta で表したもの、右は半径が1より小さいときに内側へ縮む様子を示している。

螺旋は極が動く軌跡ではなく、極を毎サンプル掛け続けたときの信号の状態を描いたものだ。極は複素平面上の1点に固定されていて、信号の側が1サンプルごとに角度 θ だけ回り、半径 r 倍に縮む。

1周にかかるサンプル数は `360/θ`。θ が 1.06°（200Hz のローパス）なら約340サンプルで、48kHz では141Hz の音として鳴る。

## 具体例・コード

2次方程式を解いて、半径と角度を出し、周波数に換算する。

```python
import math, cmath

# z^2 + a*z + b = 0  （判別式が負 → 複素根）
a, b = -1.8, 0.9
disc = cmath.sqrt(a*a - 4*b)
z1 = (-a + disc) / 2
z2 = (-a - disc) / 2

print(z1, z2)                     # 共役ペア
r = abs(z1)
theta = math.atan2(z1.imag, z1.real)

fs = 48000
print("半径 r =", round(r, 4))          # 1 に近いほど減衰しにくい
print("角度 θ =", round(math.degrees(theta), 2), "度")
print("周波数に換算 =", round(theta / (2*math.pi) * fs), "Hz")
# 極形式でも書ける
print("極形式:", round(r, 4), "* e^{i", round(math.degrees(theta),1), "度}")
```

出力は半径 0.9487、角度 18.43度、周波数 2458Hz。この点が極なら、約2.5kHz で軽く響き、ゆっくり減衰するフィルタになる。

## つまずきポイント

- i を「存在しない数」と覚える。存在するかどうかではなく、回転を表す記号として使うもの。
- 角度を度で計算する。プログラムの三角関数はラジアンを取るので、`math.degrees` は表示にだけ使う。
- 絶対値と実部を混同する。`|z|` は原点からの距離で、実部 x とは別の量。
- 共役の意味を忘れる。実係数のフィルタでは複素根が必ずペアで出る。
- r が1の状態を普通だと思う。減衰しないことは発振の境界にあたる。
- θ から周波数への換算を忘れる。θ は角度、f は Hz なので `f = θ/(2π)·fs` を挟む。
